# Guía de citas Chicago Author-Date

Referencia rápida para el skill document-analyzer.

## Reglas generales

- Los títulos de libros y revistas van en *cursiva*
- Los títulos de artículos y capítulos van entre "comillas"
- El año va después del autor, no al final
- En español: "ed." para editor, "eds." para editores
- Si son 2 autores: Apellido1 y Apellido2
- Si son 3 o más autores: Apellido1 et al.

## Tipos de fuente

### Libro
```
Apellido, Nombre. Año. *Título completo*. Ciudad: Editorial.
```

### Libro con editor
```
Apellido, Nombre, ed. Año. *Título completo*. Ciudad: Editorial.
```

### Artículo en revista académica
```
Apellido, Nombre. Año. "Título del artículo." *Nombre de la Revista* Volumen (Número): páginas–páginas.
```

### Capítulo en libro editado
```
Apellido, Nombre. Año. "Título del capítulo." En *Título del libro*, editado por Nombre Apellido, páginas–páginas. Ciudad: Editorial.
```

### Tesis o disertación
```
Apellido, Nombre. Año. "Título de la tesis." Tipo de tesis, Universidad.
```

### Documento institucional / reporte
```
Institución. Año. *Título del documento*. Ciudad: Institución.
```

### Página web / artículo en línea
```
Apellido, Nombre. Año. "Título del artículo." *Nombre del sitio*. Última modificación o acceso [fecha]. URL.
```

### Documento sin autor identificado
```
*Título del documento*. Año. Ciudad: Editorial o Institución.
```
